# Responsive Landing Page 🌐

## 📌 Project Description

This project is a modern and responsive landing page built using HTML, CSS, and JavaScript.

The website is designed to provide a clean, attractive, and user-friendly experience across different screen sizes, including desktops, tablets, and mobile devices.

## ✨ Features

- Responsive navigation bar
- Attractive hero banner
- Call-to-action (CTA) button
- About section
- Features section with interactive cards
- Contact section
- CSS hover effects and smooth transitions
- Floating animation
- Mobile navigation menu
- Responsive layouts using CSS Flexbox and Media Queries

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, Flexbox, animations, and responsive design
- **JavaScript** – Interactive mobile navigation menu

## 📂 Project Structure

responsive-landing-page/

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the landing page.

No additional installation is required.

## 📱 Responsive Design

The website is designed and tested for:

- Desktop – 1440px
- Tablet – 768px
- Mobile – 375px
